# Copy My Gesture

A simple browser game that asks the player to copy a randomly selected hand gesture.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- MediaPipe Tasks Vision Gesture Recognizer
- Browser Camera API (`getUserMedia`)
- GitHub Pages compatible

## Run
Open `index.html` through a local web server (recommended) or deploy the folder to GitHub Pages.
Camera access generally requires HTTPS or localhost.

## Supported gestures
Closed Fist, Open Palm, Pointing Up, Victory, Thumbs Up, Thumbs Down, I Love You.

## Privacy
The app processes the camera stream in the browser. It does not include a server or database.
